**Grafana provisioning conventions** (Grafana ≥10 docs):
- Data sources: YAML files under `/etc/grafana/provisioning/datasources/`, each declares `apiVersion: 1` and a `datasources:` list with `name`, `type`, `url`, etc.
- Dashboards: a "dashboard provider" YAML file under `/etc/grafana/provisioning/dashboards/` declares a `providers:` list, each provider's `options.path` points at a directory of JSON dashboard files mounted somewhere (typically `/var/lib/grafana/dashboards`).
- All three provisioning paths come from the bind mounts declared in plan 02-01 (compose `grafana` service).

**Network**: Grafana reaches the rest of the stack via service-name DNS on the default compose network. `loki:3100`, `postgres:5432`.

**Postgres credentials** (from CONTEXT.md decision: reuse dev creds): user `postgres`, password `postgres`, db `book_scraper`. The Grafana data source uses these.

Run the smoke test. This task produces no files; its output is a clean exit code + recorded confirmation in the SUMMARY.md.

```bash
# Step A: pull images (one-time bandwidth, ~200 MB total)
docker compose pull loki promtail grafana

# Step B: bring up the full stack
HTTP_PROXY="" HTTPS_PROXY="" http_proxy="" https_proxy="" ALL_PROXY="" all_proxy="" docker compose up -d

# Step C: wait for healthchecks AND running state (up to 120 s)
# Services with healthchecks (postgres, scraper, dashboard, grafana) must
# reach `healthy`. Services without healthchecks (flaresolverr, loki,
# promtail) only need to be `running` — their authoritative readiness
# probe runs in steps E and onwards via curl.
deadline=$((SECONDS + 120))
services_with_healthcheck="postgres scraper dashboard grafana"
services_without_healthcheck="flaresolverr loki promtail"
while [ $SECONDS -lt $deadline ]; do
  all_ok=1
  for svc in $services_with_healthcheck; do
    state=$(docker inspect --format '{{.State.Health.Status}}' "book-scraper-${svc}-1" 2>/dev/null || echo "missing")
    if [ "$state" != "healthy" ]; then all_ok=0; break; fi
  done
  if [ $all_ok -eq 1 ]; then
    for svc in $services_without_healthcheck; do
      state=$(docker inspect --format '{{.State.Status}}' "book-scraper-${svc}-1" 2>/dev/null || echo "missing")
      if [ "$state" != "running" ]; then all_ok=0; break; fi
    done
  fi
  if [ $all_ok -eq 1 ]; then break; fi
  sleep 5
done

# Step D: snapshot of running services
docker compose ps --format json | jq -r '.[] | select(.State == "running") | .Service' | sort

# Step E: Loki is ready (this is Loki's authoritative readiness check
# since it has no compose healthcheck)
curl -fs http://localhost:3100/ready
echo

# Step E2: Promtail is ready (same — Distroless, no compose healthcheck)
curl -fs http://localhost:9080/ready
echo

# Step F: trigger at least one dashboard log line by hitting a route
curl -fs http://localhost:8000/ -o /dev/null
sleep 10  # give Promtail a chance to scrape

# Step G: confirm Loki has at least one line tagged service=dashboard
curl -fs --data-urlencode 'query={service="dashboard"}' --data-urlencode 'limit=5' \
  http://localhost:3100/loki/api/v1/query | tee /tmp/loki-smoke.json
test "$(jq -r '.data.result | length' < /tmp/loki-smoke.json)" -gt 0

# Step H: Grafana data sources are provisioned (admin/admin)
curl -fsu admin:admin http://localhost:3000/api/datasources | jq '[.[] | {name, type}]'
# Expected: at least 2 entries: name="Loki" type="loki" and name="Postgres (book_scraper)" type="postgres"

# Expected: uid="observability-placeholder", title="Observability — placeholder"
```
